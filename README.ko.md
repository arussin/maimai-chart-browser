# maimai.party · 채보 브라우저

[English](README.md) · [简体中文](README.zh-Hans.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

다국어 지원 관리: [기준 UI 문구, 게임 용어 및 다국어 검색 데이터 재생성](docs/LOCALIZATION.md).

독립형 정적 채보 브라우저, 재사용 가능한 Python 분석 엔진, 읽기 전용 Kamaitachi 다운로드 도구입니다. 개인 추천은 다운로드 또는 내보내기 시 계산하며, 검색·필터·Flow·구조 비교는 화면에서 직접 조작할 수 있습니다.

[영구 보관하는 공식 곡 목록](docs/REGISTRY_IMPLEMENTATION.md)은 알려진 곡과 채보 유형을 선택적인 채보 전사 및 분석 데이터와 분리합니다. 검토된 일본판·국제판 수집본에는 메타데이터만 있는 채보도 포함되며, 기존 링크와 Session Report의 연동 규약을 유지합니다.

[관리자가 실행하는 카탈로그 갱신 절차](docs/CATALOG_UPDATES.md)는 원본 갱신, 캐시된 분석, 메타데이터, 정확한 mai-notes 플레이어 링크를 함께 준비하고 변경 보고서와 검증된 게시 결과를 제공합니다. 재생 가능한 항목은 YouTube 옆에 **mai-notes simai player**로 표시되며, 선택한 난이도의 채보로 연결됩니다.

Python 3.11+가 필요합니다. 패키지에는 실행 시 필요한 외부 의존성이 없으며 보고서 라이브러리도 필요하지 않습니다. 체크아웃한 저장소에서 `python -m pip install .`로 설치하세요.

공개 브라우저에 개인 달성률과 보관된 채보 기록을 표시할 수도 있습니다. 설정에서 플레이어 파일을 가져오거나 Session Report가 전달하는 데이터를 받아 사용하세요. 데이터는 브라우저 안에 머물며, 기기에 저장할지는 선택할 수 있습니다. 개인 필터를 접어도 선택은 유지됩니다. 기록이 있는 채보에는 색상으로 구분한 등급 문자, 작은 콤보·싱크 아이콘과 **내 기록** 표시가 함께 나타납니다. 플레이어 정보, 수집 범위 및 저장 설정은 설정 메뉴에서 관리합니다. 채보를 펼치면 측정값과 패턴이 **채보 상세** 아래에, 이어서 **내 데이터**와 보관된 기록이 표시됩니다. 두 영역은 곡을 바꾸거나 다시 방문해도 펼침 상태를 기억합니다. 비교와 비슷한 채보 찾기는 버전 이미지 옆의 메인 카드에 유지됩니다.
자세한 내용은 [개인 데이터, 정확한 링크 및 공개 매칭 인터페이스](docs/PLAYER_DATA.md)를 참고하세요.

## 미리보기

```sh
maimai-chart demo --output output/site
python -m http.server 8765 --bind 127.0.0.1 --directory output/site
```

`http://127.0.0.1:8765`를 여세요. 내장 데모는 가상의 데이터이며 실제 게임 수록 범위를 나타내지 않습니다. 검토된 실제 메타데이터로 빌드하려면 `maimai-chart site --catalog catalog.json --catalog-version RELEASE --output output/site`를 사용하세요. 카탈로그 버전은 변경 불가능하며, 다시 빌드해도 이전 릴리스와 링크가 보존됩니다. 생성된 디렉터리를 매니페스트 및 리소스와 함께 정적 파일로 제공하면 됩니다. 계정 서비스, 업로드 엔드포인트 또는 애플리케이션 서버는 필요하지 않습니다. [공개 배포 계획](docs/PUBLIC_RELEASE.md)은 진행 중인 패턴 검출 목표를 완료한 뒤에 이어집니다. 소스 공개, maimai.party 호스팅, 커뮤니티 기여, 관리자만 수행하는 공식 코퍼스 게시를 다룹니다. [기여 안내](CONTRIBUTING.md)도 참고하세요.

두 브라우저 페이지 모두 maimai.party 워드마크를 사용하며, `.party`에는 Deluxe에서 영감을 받은 색상을 적용합니다. Stripe를 활성화하면 소개 화면에 **GitHub에서 보기**와 **maimai.party 후원**가 함께 표시됩니다. 푸터에는 독립 팬 프로젝트의 권리 안내와 **크레딧 및 감사**가 유지됩니다. [출처 표기와 자료의 역할](THIRD_PARTY_NOTICES.md)을 참고하세요. 프로젝트 저장소는 공개되어 있으며 issue와 pull request로 기여할 수 있습니다. 공식 사이트 게시는 관리자가 명시적으로 실행하는 작업이며, [관리자 안내](docs/OWNER_PUBLICATION.md)에 설명되어 있습니다.

배포된 HTTPS 사이트는 전반적인 페이지 조회 수를 파악하기 위해 Google Analytics를 선택적으로 사용합니다. 방문자가 동의해야만 로드되며, 로컬 미리보기는 제외됩니다. 개인 파일, 검색어, 선택한 채보 및 전체 URL은 분석 이벤트 데이터에 포함되지 않습니다. 푸터에서 개인정보 안내를 확인하고, 기록을 지우지 않고도 동의를 철회할 수 있습니다. [분석 설정 및 출시 검증](docs/ANALYTICS.md)을 참고하세요.

Explore와 함께 전체 연구용 브라우저를 열려면 demo 또는 site 명령에 `--lab-package PATH/TO/challenge-v1`을 추가하세요. 고정된 연구 패키지를 검증하고, 변경 불가능한 릴리스 매니페스트를 통해 별도 데이터 파일을 참조합니다. 메인 페이지에서 연결되는 연구용 브라우저에는 세 가지 화면이 있습니다.

- **채보:** 장르, 버전, 난이도, 채보 유형, 레벨 범위 필터를 조합합니다. 여러 버전을 동시에 선택할 수 있습니다. 각 곡/유형 행의 난이도 선택기에는 필터와 일치하는 정확한 채보만 표시되며, 레벨이 같은 MASTER/RE:MASTER 채보도 구분됩니다. 선택한 난이도에 따라 행 색상, 레벨, 원본 BPM, 입력 속도 및 비교 동작이 결정됩니다. 행의 다른 부분을 누르면 상세 내용을 엽니다. 열 제목을 눌러 정렬하거나 순서를 뒤집을 수 있습니다. Shift를 누른 채 클릭하거나 **정렬 우선순위 유지**를 사용하면 동률일 때 적용할 추가 정렬 기준을 넣을 수 있습니다. 표시된 우선순위 칩으로 규칙을 제거할 수 있으며, 항상 선택한 채보를 기준으로 정렬합니다. **난이도**는 표시 레벨(10, 10+, 11), **상수**는 보관된 소수점 채보 상수로 정렬합니다. 알 수 없는 값은 오름차순과 내림차순 모두 마지막에 표시됩니다. 정렬이나 검색을 바꿔도 필터는 유지됩니다.
  곡 검색은 커뮤니티에서 쓰는 로마자 표기와 별칭도 지원합니다. **Umiyuri**로 **ウミユリ海底譚**을, **Senbonzakura**로 **千本桜**을 찾을 수 있습니다. 공백, 문장 부호, 대소문자, 전각 라틴 문자를 허용합니다. 같은 별칭은 Explore와 두 비교 선택기에서도 동작하며, 화면에는 원래 곡명이 표시됩니다. [별칭 지원 범위와 출처](docs/SONG_SEARCH.md)를 참고하세요. 원본의 곡 BPM은 표시용 메타데이터이며, 실제 구간에서는 템포가 바뀔 수 있습니다. 알 수 없는 BPM은 그대로 미상으로 남고 양방향 정렬 모두 마지막에 표시됩니다.
  **YouTube 검색**은 곡명, 채보 유형, 선택한 난이도로 새 탭을 엽니다. 비교 선택과 유사 채보 결과에도 같은 링크가 표시됩니다. 이는 검색 링크이며 검증된 영상 연결이 아니므로 영상의 존재나 이용 가능 여부를 보장하지 않습니다. 방문자가 링크를 누르기 전에는 YouTube 영상, 썸네일 또는 요청을 로드하지 않습니다. 곡명이 없는 항목에는 검색 링크가 없습니다.
  준비된 실험적 패턴 태그는 학습 항목으로 연결되며, 패턴 필터는 일치하는 난이도만 남깁니다. 상세 화면에는 관측된 횟수와 채보 내 시간 구간이 표시됩니다. 각 행에는 평균 밀도와 짧은 피크 표시를 포함한 24구간 Flow 그래프가 있습니다. 작은 그래프는 각자의 최댓값을 기준으로 표시하고, 비교 그래프는 같은 세로축 척도를 공유합니다.
- **패턴 사전:** 작성된 예시와 설명을 담은 56개 학습 항목을 알파벳순으로 제공합니다. 모든 데모에서 재생, 한 단계 진행, 속도 및 진행 위치를 조작할 수 있으며 0.1×, 0.25×, 0.5×, 1× 재생을 지원합니다. 대조 사례, 변형 및 적용 한계는 학습 데이터에 보존됩니다. 도해와 재생 화면에서 동시 입력은 금색으로 표시됩니다. 입력 패턴은 타이밍과 위치 보기로, 채보 특성은 활동 그래프나 강조된 구간으로 보여 줍니다. 현재 이벤트 설명이 각 단계를 안내합니다. Umiyuri는 자료를 참고하여 반복적으로 나타나는 한 형태를 한정된 범위에서 설명합니다. 학습 예시는 실제 채보에 라벨을 붙이거나 검출기를 검증하는 자료가 아닙니다. 영어 별칭에는 jacks, sweeps, spins, connected slides가 포함됩니다. 추가된 커뮤니티 패턴 10종과 관련 구조 형태 10종에는 영어 설명, 필요한 경우의 개략적인 곡선, 적용 범위가 명시된 실험적 인식 규칙이 있습니다. [커뮤니티 패턴 참고 자료와 지원 범위](docs/patterns/COMMUNITY_PATTERNS.md), [사전 점검 목록과 남은 검토](docs/PATTERN_DICTIONARY.md)를 참고하세요.
- **채보 비교:** 검색 가능한 선택기로 아무 채보 두 개를 고르거나, 하나를 선택한 뒤 카탈로그에서 **비슷한 채보 찾기**를 실행합니다. 비교에는 입력 속도, 리듬, 동시 입력, HOLD, SLIDE 및 배치에 관한 기존 측정값을 사용합니다. 유사 결과는 곡 묶음당 채보 하나를 보여 주며, 현재 채보 필터를 적용할 수도 있습니다. 링크는 두 채보의 ID와 카탈로그 버전을 유지합니다. 공통·상이한 패턴, 출현 횟수/빈도, 나란히 놓인 Flow 그래프가 측정값 표보다 먼저 표시됩니다. **패턴 및 측정값**은 실험적 패턴의 존재, 출현 빈도, 시간 비중에 총 60%를, 측정된 조작 요구량에 40%를 배정합니다. 드문 패턴에는 더 높은 가중치를 주며, 검출을 지원하지 않는 영역은 패턴이 없는 것으로 취급하지 않습니다. **측정값** 모드는 기존 순위를 유지합니다. 이는 실험적 비교로, 검증된 커뮤니티 채보 분류나 개인 추천이 아닙니다. 준비된 채보 쌍에서는 동기화된 구간 애니메이션을 계속 사용할 수 있으며, 기존 예시는 **준비된 구간 데모** 아래에 있습니다.

화면은 보고서 사이트의 흰색/청록색 디자인을 따릅니다. 사전 링크는 연구 카탈로그 버전과 패턴 ID를 유지합니다. 연구 데이터는 Python 배포본이나 소스 저장소에 포함되지 않으며 개인 기록을 받을 수 없습니다.

보관된 입력으로 연구용 패턴/Flow 확장을 준비하려면 다음을 실행하세요.

```sh
python scripts/build_research_overview.py RETAINED_SOURCE EXISTING_PACKAGE NEW_PACKAGE
maimai-chart demo --output output/site --lab-package NEW_PACKAGE
```

이 오프라인 명령은 원본 해시를 보존하면서 각 정확한 채보에 기존 실험적 검출기 14개와 Flow 계산을 실행합니다. 이어서 처리할 수 있는 캐시를 기록하며, 모든 채보가 완료된 뒤에만 새 패키지 매니페스트를 게시합니다. 원래 패키지, 순위, 아카이브 및 개인 서비스는 변경되지 않습니다. 브라우저 빌드는 변경 불가능한 릴리스를 추가하며, 이전 링크는 종전 데이터를 유지합니다.

## 개인 기록 다운로드 및 준비

```sh
maimai-chart download USERNAME --game maimaidx --store .snapshots/player
maimai-chart prepare --snapshot .snapshots/player/captures/SNAPSHOT_ID/snapshot.json --catalog catalog.json --catalog-version RELEASE --mapping reviewed-mapping.json --output output/my-results.json
```

다운로드 도구는 Kamaitachi에 이미 있는 개인 최고 기록(PB)과 최근 점수를 읽습니다. 게임 데이터 가져오기를 실행하지 않습니다. 접근에 토큰이 필요하면 프로세스 환경 변수로 `KAMAITACHI_API_TOKEN`을 제공하세요. 토큰은 스냅샷이나 브라우저 파일에 기록되지 않습니다. 자동 재시도나 예약 요청도 수행하지 않습니다.

한 명령으로 다운로드와 준비를 모두 수행하려면 `download`에 네 가지 준비 옵션을 추가하세요. 선택 옵션인 `--settings settings.json`으로 기존 추천 정책, 연습 목표 및 할당량을 선택합니다. 목표를 바꾸면 파일을 다시 준비해야 합니다. **내 기록 열기**로 결과 파일을 여세요. 파일은 해당 탭의 메모리에 머무르며, **내 기록 지우기** 또는 페이지 새로고침으로 제거됩니다. 개인 데이터는 업로드되지 않습니다.

각 저장소는 한 플레이어/게임에 속합니다. 매니페스트에는 성공한 변경 불가능 캡처와 최신 신원 정보가 기록됩니다. 각 캡처에는 `pbs.json`, `recent.json`, `snapshot.json`이 포함됩니다. 확인 가능한 플레이는 정확한 점수 ID로 누적하지만 기록은 여전히 불완전합니다. 최근 점수를 주기적으로 조회해도 과거의 모든 플레이를 복원할 수는 없습니다. 중단된 캡처는 기존 최신 캡처 포인터를 덮어쓰지 못합니다. 남아 있는 잠금 파일을 수동으로 제거하기 전에는 기록 중인 프로세스가 없는지 확인해야 합니다.

## 연동

Python 인터페이스: `maimai_analyzer.catalog.build_catalog`, `maimai_intelligence.snapshots.download_snapshot`, `maimai_intelligence.bundles.prepare_player_bundle`, `export_report_bundle`. 공개 요약 매칭용 `maimai_analyzer.challenge_similarity.query_demands`는 구간 창 없이 기존 채보 프로필과 기준 척도를 입력받습니다. 브라우저도 동등한 백분위 및 거리 계산을 사용합니다. [버전별 인터페이스 규약](docs/CONTRACTS.md)과 [보고서 연동](docs/REPORT_INTEGRATION.md)을 참고하세요.

일반적인 보고서 설치에는 이 저장소나 엔진이 필요하지 않습니다. 준비된 카드와 특정 카탈로그로 연결되는 링크는 선택 기능입니다. 기존 아카이브를 이전하거나 과거 데이터를 소급해서 채울 필요가 없습니다.

현재 채보 전사 연구 자료는 평가용 데이터입니다. 개인 정보가 포함되지 않으며, 검증된 Rating 추천에 사용할 수 없습니다. 개인 번들에는 명시적인 검토를 거친 정확한 제공자-카탈로그 매핑과 해당 용도에 적합하다고 검증된 카탈로그가 필요합니다. 알 수 없는 달성률, 누락된 플레이, 확인되지 않은 이용 가능 여부는 그대로 미상으로 유지됩니다.

## 개발

`PYTHONPATH=src`를 설정하고 저장소 루트도 가져오기 경로에 포함한 뒤 `python -m unittest discover -s tests`를 실행하세요. 브라우저 테스트는 `tests/browser`에 있습니다. `npm ci`로 고정된 의존성을 설치하고 Playwright 브라우저를 설치한 다음 `npm test`를 실행하세요. 빌드 백엔드는 빌드 의존성을 다운로드하지 않고 wheel과 소스 배포본을 지원합니다. 원래 분석기와 Python/JavaScript 유사도 계산 일치 여부를 검증하는 테스트 데이터는 보존됩니다.

기존 연구 자료 수집/빌드 스크립트와 Challenge Lab 렌더러는 별도로 보존됩니다. 이들은 명시적으로 실행하는 오프라인/연구 절차이며, 메인 브라우저를 연다고 실행되지 않습니다. 출처 표기: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## 채보 필터

난이도는 체크박스 메뉴로, BASIC부터 RE:MASTER까지 원하는 조합을 선택합니다. 각 행에는 조건에 맞는 난이도 중 현재 표시할 난이도를 고르는 선택기가 남습니다. 레벨 범위에는 드래그와 키보드 조작을 지원하는 두 핸들과 편집 가능한 최소/최대 필드가 있습니다. Enter를 누르거나 필드를 벗어나면 적용됩니다. `13.5`는 `13+`로 입력할 수 있습니다. 범위는 선택한 카탈로그에 있는 레벨을 기준으로 합니다. 잘못된 텍스트는 적용된 범위를 바꾸지 않으며, 한쪽 값을 다른 쪽을 넘어서 입력하면 두 끝이 모두 해당 레벨로 이동합니다. 필드를 비우면 그쪽 끝이 전체 범위의 끝으로 복원됩니다. 레벨 초기화는 다른 필터를 바꾸지 않습니다. 비교에서 “채보 필터를 적용하여 검색”을 켜면 같은 난이도/범위 제한을 사용합니다.

패턴은 검색 가능한 체크박스 메뉴를 사용합니다. 검색에는 별칭이 포함되며, 선택한 패턴 중 하나라도 일치하면 결과에 포함됩니다. 선택한 패턴은 제거 가능한 칩으로 표시되며, 반복 가능한 `pattern-filter` URL 매개변수로 저장되고 복원됩니다. 기존 단일 패턴 링크와 사전 탐색도 계속 동작합니다. 검출을 지원하지 않는 패턴은 비활성 상태로 표시됩니다.

## 선택적 공개 이미지

재킷 이미지와 버전 로고를 한 번 준비한 뒤 생성된 로컬 WebP 파일을 제공하세요. 준비에는 Pillow(`python -m pip install Pillow`)가 필요하지만, 이미 준비된 패키지를 탐색하거나 빌드할 때는 일반적인 외부 의존성 없는 설치를 유지합니다.

```sh
python -m scripts.prepare_public_artwork output/challenge-patterns-v1 output/challenge-artwork-v1 --cache output/artwork-cache/downloads
maimai-chart demo --output output/site --lab-package output/challenge-artwork-v1
```

이 명령은 공개 메타데이터와 이미지만 읽습니다. `--offline`은 네트워크 접근 없이 캐시를 재사용합니다. 이미지가 없으면 중립적인 자리표시자를 보여 줍니다. 재킷은 정규화한 곡명과 **아티스트가 모두** 유일하게 일치해야 합니다. 이 표시용 조회는 채보의 동일성을 확정하거나 개인화를 활성화하지 않습니다. 패키지에는 원본 URL, 원본 해시 및 변환된 이미지 해시가 기록됩니다. 브라우저는 같은 사이트의 리소스만 로드하며, 계정 정보, 원격 이미지 요청 또는 제삼자 스크립트를 사용하지 않습니다.

보관된 원본에는 이미 CiRCLE(곡/유형 항목 78개, 채보 315개)과 CiRCLE PLUS(항목 18개, 채보 75개)가 포함됩니다. 2026-09-11에 상위 저장소의 기본 브랜치를 확인했으며, 커밋 `e164add85213bab150e1487d5eb15ccb631aedb9`는 추가되거나 변경된 경로 없이 보관된 트리와 일치했습니다. 상위 저장소의 최신 릴리스는 CiRCLE PLUS 출시 업데이트인 [v1.66_1.0.9.0](https://github.com/Neskol/Maichart-Converts/releases/tag/v1.66_1.0.9.0)입니다. 이는 원본 자료의 범위이며 현재 게임 전체 카탈로그를 뜻하지 않습니다. 버전 선택기에는 실제 곡 수와 채보 수가 표시됩니다.
