# Badge artwork and provenance

The committed artwork/template.png is the approved visual base with placeholders removed so code can render current counts. Earlier design and ear-stacking reference images remain preserved locally; they are not runtime inputs.

Flags are the original famfamfam images by Mark James, published as public domain, from the revision and per-image hashes in artwork/provenance.json. Nunito ExtraBold 800 outlines are derived from @fontsource/nunito 5.3.0 under the SIL Open Font License 1.1; retain artwork/NUNITO-LICENSE.txt and the source hash. No external font or image request is needed to display the SVG.

The existing template was created through the image-generation/editing workflow. This proposal changes no artwork or layout.
