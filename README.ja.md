# maimai.party · 譜面ブラウザー

[English](README.md) · [简体中文](README.zh-Hans.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

多言語対応の保守：[UI 文言、ゲーム用語、多言語検索データの再構築](docs/LOCALIZATION.md)。

単体で動作する静的な譜面ブラウザー、再利用可能な Python 分析エンジン、読み取り専用の Kamaitachi ダウンローダーです。個人向けのおすすめはダウンロード／エクスポート時に計算され、検索、絞り込み、Flow、構造の比較は画面上で操作できます。

[永続的に保持する公式楽曲一覧](docs/REGISTRY_IMPLEMENTATION.md)は、既知の楽曲・譜面タイプと、任意の譜面書き起こし・分析データを分けて管理します。確認済みの日本版・国際版の取得データには、メタデータのみの譜面も含まれます。従来のリンクと Session Report の既存の連携仕様も維持します。

[管理者が実行するカタログ更新手順](docs/CATALOG_UPDATES.md)では、ソースの更新、キャッシュ済みの分析、メタデータ、正確な mai-notes プレーヤーへのリンクをまとめて準備し、変更レポートと公開結果の検証を行います。再生可能な一致項目は YouTube の横に **mai-notes simai player** として表示され、選択中の難易度の譜面に対応します。

Python 3.11+ が必要です。パッケージに実行時の外部依存関係はなく、レポート用ライブラリも不要です。チェックアウトしたリポジトリから `python -m pip install .` でインストールしてください。

公開ブラウザーでは、自分の達成率や保存された譜面履歴も表示できます。設定からプレーヤーファイルを読み込むか、Session Report からの引き継ぎを利用してください。データはブラウザー内に留まり、端末への保存は任意です。個人用の絞り込みを折りたたんでも選択内容は消えません。記録のある譜面には、色付きのランク文字、小さなコンボ／シンクアイコン、控えめな**あなた**のラベルが表示されます。プレーヤー情報、取得範囲、保存方法は設定で管理します。譜面を開くと、測定値と配置は**譜面の詳細**に、その後に**あなたのデータ**と保存された履歴がまとまって表示されます。両方のグループは、楽曲を切り替えたり再訪したりしても開閉状態を記憶します。比較と似た譜面を探す操作は、バージョン画像の横にあるメインカードに残ります。
詳しくは[個人データ、正確なリンク、公開マッチングインターフェース](docs/PLAYER_DATA.md)を参照してください。

## プレビュー

```sh
maimai-chart demo --output output/site
python -m http.server 8765 --bind 127.0.0.1 --directory output/site
```

`http://127.0.0.1:8765` を開きます。付属デモのデータは架空のもので、ゲームの収録範囲を示すものではありません。確認済みの実際のメタデータで構築するには、`maimai-chart site --catalog catalog.json --catalog-version RELEASE --output output/site` を使用します。カタログの各バージョンは変更されず、繰り返し構築しても古いリリースとリンクを保持します。生成されたディレクトリを、マニフェストとアセットを含めて静的ファイルとして配信してください。アカウントサービス、アップロード用エンドポイント、アプリケーションサーバーは不要です。[公開リリース計画](docs/PUBLIC_RELEASE.md)は、進行中の配置検出の目標を完了した後に続きます。ソース公開、maimai.party のホスティング、コミュニティからの貢献、管理者のみが行う公式コーパスの公開を扱います。[貢献ガイド](CONTRIBUTING.md)も参照してください。

両方のブラウザーページは maimai.party のワードマークを使い、`.party` の部分は Deluxe をイメージした配色です。Stripe が有効な場合、サイト紹介には **GitHub で見る**と **maimai.party を支援**が並びます。フッターには独立したファンプロジェクトの権利に関する注意書きと**クレジットと謝辞**を保持します。[出典表記と各資料の役割](THIRD_PARTY_NOTICES.md)を参照してください。プロジェクトのリポジトリは公開されており、issue と pull request で貢献できます。公式サイトの公開は管理者が明示的に実行する操作です。手順は[管理者ガイド](docs/OWNER_PUBLICATION.md)に記載しています。

公開された HTTPS サイトでは、大まかなページ閲覧状況を把握するために Google Analytics を任意で利用できます。訪問者の同意後にのみ読み込み、ローカルプレビューは対象外です。個人ファイル、検索内容、選択した譜面、完全な URL は分析イベントに含めません。フッターでプライバシーの説明を確認し、成績を消去せずに同意を撤回できます。[分析機能の設定と公開時の検証](docs/ANALYTICS.md)を参照してください。

Explore と併せて研究用ブラウザー全体を開くには、demo または site コマンドに `--lab-package PATH/TO/challenge-v1` を追加してください。固定された研究用パッケージを検証し、変更されないリリースマニフェストを通して別ファイルのデータを参照します。メインページからリンクする研究用ブラウザーには、次の三つの画面があります。

- **譜面：**ジャンル、バージョン、難易度、譜面タイプ、レベル範囲で絞り込みます。複数のバージョンを同時に選択できます。各楽曲／タイプの行には、条件に一致する実際の譜面を選べる難易度セレクターがあり、同じレベルの MASTER/RE:MASTER も区別します。選択中の難易度に応じて、行の色、レベル、ソースの BPM、入力速度、比較操作が決まります。行のほかの部分をクリックすると詳細が開きます。列見出しで並べ替えと順序の反転ができ、Shift キーを押しながらクリックするか、**並べ替えの優先順位を保持**を使うと同値の場合の追加条件を設定できます。表示された優先順位のチップから規則を削除できます。並べ替えには常に選択中の譜面を使います。**難易度**は表示レベル（10、10+、11）、**定数**は保持された小数の譜面定数で並べ替えます。不明な値は昇順・降順のどちらでも最後になります。並べ替えや検索を変更しても絞り込み条件は保持します。
  楽曲検索はコミュニティで使われるローマ字表記や別名にも対応します。**Umiyuri** で **ウミユリ海底譚**、**Senbonzakura** で **千本桜** が見つかります。空白、句読点、大文字・小文字、全角英字の違いを許容します。同じ別名は Explore と両方の比較セレクターでも使えますが、表示する曲名は元のままです。[別名の対応範囲と出典](docs/SONG_SEARCH.md)を参照してください。ソースの楽曲 BPM は表示用メタデータであり、区間によってテンポが変わる場合があります。不明な BPM は不明のまま、どちらの並び順でも最後に表示します。
  **YouTube 検索**は曲名、譜面タイプ、選択中の難易度を使って新しいタブを開きます。比較対象や類似結果にも同じリンクを表示します。これは検索リンクであり、確認済みの動画との対応ではありません。動画が利用できる保証もありません。訪問者がリンクを開くまでは、YouTube の動画、サムネイル、リクエストを読み込みません。曲名が空の項目には検索リンクがありません。
  準備済みの実験的な配置タグは解説にリンクし、配置による絞り込みでは一致する難易度だけを残します。詳細には観測した回数と譜面内の時間区間を表示します。各行に 24 区間の Flow グラフがあり、平均密度と短時間のピークを示します。小型グラフはそれぞれの最大値に合わせ、比較では共通の縦軸を使います。
- **配置辞典：**作成した例と説明を含む 56 の解説をアルファベット順に掲載しています。すべてのデモで再生、ステップ送り、速度、再生位置を操作でき、0.1×、0.25×、0.5×、1× に対応します。対照例、変形、適用限界も解説データに保持しています。図と再生画面では同時入力を金色で表示します。入力配置にはタイミングと位置のビューを、譜面の特徴には活動グラフや強調したフレーズを使います。現在のイベント表示が各ステップを説明します。Umiyuri では、資料を参考に、繰り返し現れる一つの形を範囲を限定して図解しています。学習用の例は実譜面へのラベル付けや検出器の検証には使いません。英語の別名には jacks、sweeps、spins、connected slides があります。追加されたコミュニティ由来の十種類の配置と関連する十種類の構造には、英語の解説、必要に応じた模式的な曲線、適用範囲を限定した実験的な認識規則を用意しています。[コミュニティ配置の参考資料と対応範囲](docs/patterns/COMMUNITY_PATTERNS.md)、[辞典のチェックリストと残りのレビュー](docs/PATTERN_DICTIONARY.md)を参照してください。
- **譜面比較：**検索可能なセレクターで任意の二つの譜面を選ぶか、一つを選んでカタログ全体から**似た譜面を探す**ことができます。入力速度、リズム、同時入力、HOLD、SLIDE、配置に関する既存の測定値で比較します。類似結果は楽曲のグループごとに一譜面を表示し、現在の絞り込み条件も任意で適用できます。リンクには両方の譜面 ID とカタログバージョンが残ります。共通・相違する配置、出現回数／頻度、並列の Flow グラフを測定値の表より前に表示します。**配置と測定値**では、実験的な配置の有無、出現頻度、時間的な占有率を合計 60%、測定された操作上の要求を 40% の割合で重視します。珍しい配置には高い重みを与え、検出に対応していない範囲を「存在しない」とは扱いません。**測定値**は以前の順位付けを維持します。これらは実験的な比較であり、検証されたコミュニティの譜面分類や個人向けのおすすめではありません。準備済みのペアでは同期した区間アニメーションを引き続き利用でき、従来の例は**用意された区間デモ**にあります。

画面はレポートサイトの白と青緑を基調にしています。辞典へのリンクは研究用カタログのバージョンと配置 ID を保持します。研究データは Python 配布物やソースリポジトリには含まれず、個人の成績を受け取ることもできません。

保持済みの入力から研究用の配置／Flow 拡張を準備するには、次を実行します。

```sh
python scripts/build_research_overview.py RETAINED_SOURCE EXISTING_PACKAGE NEW_PACKAGE
maimai-chart demo --output output/site --lab-package NEW_PACKAGE
```

このオフラインコマンドはソースハッシュを保持し、各譜面に既存の 14 個の実験的な検出器と Flow 計算を適用します。再開可能なキャッシュを書き込み、すべての譜面の処理が完了してから新しいパッケージマニフェストを公開します。元のパッケージ、順位、アーカイブ、個人用サービスは変更しません。ブラウザーの構築は変更されないリリースを追加し、古いリンクは以前のデータを保持します。

## 個人の成績をダウンロードして準備する

```sh
maimai-chart download USERNAME --game maimaidx --store .snapshots/player
maimai-chart prepare --snapshot .snapshots/player/captures/SNAPSHOT_ID/snapshot.json --catalog catalog.json --catalog-version RELEASE --mapping reviewed-mapping.json --output output/my-results.json
```

ダウンローダーは Kamaitachi に既にある自己ベスト（PB）と最近のスコアを読み取ります。ゲームからのインポートは実行しません。アクセスにトークンが必要な場合は、プロセスの環境変数で `KAMAITACHI_API_TOKEN` を指定してください。スナップショットやブラウザー用ファイルにトークンを書き込むことはありません。自動リトライや定期的なリクエストも行いません。

ダウンロードと準備を一つのコマンドで行うには、`download` に四つの準備オプションを追加します。任意の `--settings settings.json` で、既存の推薦方針、練習目標、割り当て数を選べます。目標を変えた場合はファイルを再作成してください。生成したファイルは**自分の成績を開く**から読み込みます。データはそのタブのメモリに留まり、**自分の成績を消去**またはページの再読み込みで削除されます。個人データをアップロードすることはありません。

各保存先は一人のプレーヤー／一つのゲームに対応します。マニフェストには成功した変更不可の取得データと最新の識別情報を記録します。各取得データは `pbs.json`、`recent.json`、`snapshot.json` を含みます。取得できたプレーは正確なスコア ID 単位で蓄積しますが、履歴は完全ではありません。最近のスコアを定期的に取得しても、過去の全プレーは復元できません。中断した取得が、前回の最新データへの参照を置き換えることはありません。残ったロックを手動で削除する際は、書き込み中の処理がないことを先に確認してください。

## 連携

Python インターフェース：`maimai_analyzer.catalog.build_catalog`、`maimai_intelligence.snapshots.download_snapshot`、`maimai_intelligence.bundles.prepare_player_bundle`、`export_report_bundle`。公開サマリーのマッチング用の `maimai_analyzer.challenge_similarity.query_demands` は、区間ウィンドウを要求せず、既存の譜面プロファイルと基準尺度を受け取ります。ブラウザーも同等のパーセンタイルと距離の計算を使います。[バージョン付きのインターフェース仕様](docs/CONTRACTS.md)と[レポート連携](docs/REPORT_INTEGRATION.md)を参照してください。

通常のレポートのインストールには、このリポジトリもエンジンも不要です。準備済みカードとカタログ固有のリンクは、任意のレポート機能です。既存アーカイブの移行や過去データの補完は必要ありません。

現在の譜面書き起こし研究は評価用データです。個人情報は含まず、検証済みの Rating 向け推薦には利用できません。個人用バンドルには、明示的なレビューを経た正確な提供元とカタログの対応付け、および用途に適していることが確認されたカタログが必要です。不明な達成率、欠けたプレー、未確認の利用可否は不明のまま扱います。

## 開発

`PYTHONPATH=src` を設定し、リポジトリのルートもインポートパスに含めて `python -m unittest discover -s tests` を実行します。ブラウザーテストは `tests/browser` にあります。`npm ci` で固定された依存関係をインストールし、Playwright のブラウザーを導入してから `npm test` を実行してください。ビルドバックエンドは、ビルド用依存関係をダウンロードせずに wheel とソース配布物を構築できます。元の分析器と、Python/JavaScript の類似度計算の一致を検証するテストデータは保持しています。

既存の研究用取得／ビルドスクリプトと Challenge Lab のレンダラーは別途保持されています。これらは明示的に実行するオフライン／研究用の手順であり、メインブラウザーを開いても実行しません。出典表記：[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 譜面の絞り込み

難易度はチェックボックス式のメニューで、BASIC から RE:MASTER まで任意の組み合わせを選べます。各行には、一致する難易度の中から現在表示するものを選ぶセレクターを残します。レベル範囲には、ドラッグとキーボード操作が可能な二つのハンドルと、編集可能な下限／上限欄があります。Enter を押すか欄からフォーカスを外すと適用します。`13.5` は `13+` として入力できます。範囲の端は、選んだカタログに存在するレベルを使います。無効な文字列では適用済みの範囲を変えません。一方の値がもう一方を越えると両端をそのレベルに移動します。欄を空にすると、その側を全範囲の端に戻します。レベルのリセットはほかの絞り込みに影響しません。比較で「譜面の絞り込み条件を使用」を有効にすると、同じ難易度／範囲の制約を適用します。

配置は検索可能なチェックボックス式メニューです。検索には別名も含み、選択した配置のいずれかに一致すれば対象になります。選んだ配置は削除できるチップとして表示され、繰り返し指定できる `pattern-filter` URL パラメーターで保存・復元されます。従来の単一配置へのリンクや辞典からの検索も引き続き動作します。検出に対応していない配置は無効として表示します。

## 任意の公開画像

ジャケット画像とバージョンロゴを一度準備し、生成されたローカルの WebP ファイルを配信します。準備には Pillow（`python -m pip install Pillow`）が必要です。準備済みのパッケージを閲覧・構築する場合は、通常どおり外部依存関係のないインストールを維持できます。

```sh
python -m scripts.prepare_public_artwork output/challenge-patterns-v1 output/challenge-artwork-v1 --cache output/artwork-cache/downloads
maimai-chart demo --output output/site --lab-package output/challenge-artwork-v1
```

このコマンドは公開メタデータと画像だけを読み取ります。`--offline` はネットワークにアクセスせずにキャッシュを再利用します。画像がない場合は中立的なプレースホルダーを表示します。ジャケットの対応付けには、正規化した曲名**とアーティスト**が一意に一致することを要求します。この表示用の照合は、譜面の同一性を確定したり個人向け機能を有効にしたりするものではありません。パッケージにはソース URL、ソースハッシュ、変換後の画像ハッシュを記録します。ブラウザーは同じサイトのアセットだけを読み込み、アカウント情報、外部画像へのリクエスト、第三者のスクリプトは使いません。

保持済みのソースには CiRCLE（楽曲／タイプの項目 78 件、譜面 315 件）と CiRCLE PLUS（18 項目、75 譜面）が既に含まれています。2026-09-11 に上流のデフォルトブランチを確認したところ、コミット `e164add85213bab150e1487d5eb15ccb631aedb9` は保持済みのツリーと一致しており、追加・変更されたパスはありませんでした。上流の最新リリースは CiRCLE PLUS 稼働開始時の更新である [v1.66_1.0.9.0](https://github.com/Neskol/Maichart-Converts/releases/tag/v1.66_1.0.9.0) です。これはソースの対応範囲であり、現在のゲーム全体のカタログではありません。バージョンセレクターには、実際の楽曲数と譜面数を表示します。
