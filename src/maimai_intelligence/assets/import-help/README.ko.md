# 플레이어 데이터 가져오기

개인 최고 기록을 채보 브라우저로 가져옵니다. 가져오기 전에 프로필을 확인하세요. 기록은 브라우저에 저장되며 공유 링크나 분석 데이터에 포함되지 않습니다.

<a id="session-report"></a>

## Session Report: 파일 또는 호스팅된 리포트

Session Report는 Kamaitachi 데이터와 보관된 이력으로 플레이어 파일을 만듭니다. 아래 두 방법은 같은 플레이어 데이터 형식을 사용합니다.

파일 업로드: Session Report에서 압축된 플레이어 파일(.gz)을 다운로드한 다음, 파일 업로드를 선택하고 해당 파일을 엽니다. 이 기기에 저장할지는 선택할 수 있습니다. 저장하지 않으면 현재 탭에서만 유지됩니다.

호스팅된 Session Report: 리포트 URL을 붙여 넣으세요. 명시적으로 공개되어 있고 브라우저의 교차 출처 접근을 허용하는 리포트는 직접 읽을 수 있습니다. 저장 및 새로고침을 선택하면 이 기기에 연결 정보가 저장됩니다. 비공개 리포트는 리포트 사이트에서 로그인한 뒤 Party에서 열기를 선택하거나 플레이어 파일을 다운로드하세요. 비공개 리포트를 새로고침할 때도 이 과정이 필요합니다.

다른 플레이어를 가져오면 활성 프로필이 바뀌며, 서로 다른 플레이어의 기록은 합쳐지지 않습니다. 읽기에 실패해도 기존 기록은 유지됩니다.

<a id="maishift"></a>

## Maishift

플레이어 데이터 가져오기에서 Maishift를 선택하세요. 본인의 공개 사용자명 또는 프로필 URL을 입력하세요. 가져오거나 저장 및 새로고침에 동의한 경우에만 Party의 가져오기 서비스가 공개 프로필과 플레이한 채보의 최고 기록을 읽습니다. Maishift 비밀번호는 필요하지 않습니다.

한 사용자명에 인터내셔널과 일본 기록이 모두 있을 수 있으며, 두 기록은 별도로 유지됩니다. 북미는 인터내셔널 기록을 사용하지만 선택 가능한 채보가 다릅니다. @jp, @intl 또는 @na가 포함된 URL은 해당 기록을 선택합니다. 사용자명이나 지역이 없는 URL은 먼저 인터내셔널 기록을 요청하고 Maishift가 실제로 반환한 지역을 사용합니다. 두 지역 모두 있으면 인터내셔널을 선택합니다. 일본 기록을 가져오려면 @jp가 포함된 프로필 링크를 붙여 넣으세요. 저장 후 새로고침은 해당 지역을 유지하며, 표시 언어는 기록 지역에 영향을 주지 않습니다.

미리보기에는 플레이어, 가져온 개인 최고 기록 수, 매칭되지 않았거나 제외된 기록이 표시됩니다. 사용자명을 누르면 선택한 Maishift 프로필이 열립니다. 레이팅 배지는 Maishift가 제공한 총 레이팅을 표시합니다. 채보별 레이팅은 해당 소스의 정수 기여도를 사용하며 필터와 정렬에 적용됩니다. 누락되었거나 추정된 레이팅은 알 수 없음으로 유지됩니다.

낮은 난이도와 STD/DX를 포함해 반환된 모든 플레이 채보의 최고 기록을 확인합니다. 검토된 정확한 매칭이 있는 기록은 브라우저에 표시합니다. 매칭되지 않은 기록도 보존하며, 채보 식별 정보가 부족한 기록은 별도로 집계합니다. 최고 기록 스냅샷으로 플레이 날짜나 세션을 만들지 않습니다.

가져오기 및 저장을 선택하면 이 브라우저에 프로필과 연결 정보가 저장됩니다. 한 번만 가져오기는 현재 탭에서만 유지됩니다. 저장된 기록을 먼저 복원한 뒤 페이지가 표시되고 온라인 상태인 등 조건을 충족하면 업데이트를 확인합니다. 같은 소스의 자동 확인은 여러 탭을 통틀어 15분에 최대 한 번입니다. 지금 새로고침에는 30초 대기 시간이 있으며, 소스의 제한에 따라 더 기다려야 할 수 있습니다.

저장된 플레이어 데이터 삭제는 프로필과 연결 정보를 지우고 모든 탭에서 새로고침을 중단합니다. 이미 표시된 기록은 페이지를 다시 불러올 때까지 남을 수 있습니다. 종료된 테스트 브라우저의 데이터는 별도로 유지됩니다. 본 사이트에서 다시 가져오세요. 사용자명은 공개 소스 식별용이며, 계정 소유권을 증명하거나 사용자명 재할당을 감지하지는 못합니다.
