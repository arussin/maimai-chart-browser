# プレイヤーデータの読み込み

**プレイヤーデータの読み込み**で利用しているサービスを開きます。以下の手順に従い、プレイヤー、地域、自己ベスト（PB）、未一致の譜面と除外されたレコードをプレビューで確認してください。記憶するとこの端末に保存され、今回のみの読み込みはこのタブで有効です。

<a id="direct-connections"></a>

## 接続と更新

Diving-Fish または LXNS への接続が利用可能な場合、アカウントへのアクセスを許可して成績を読み込めます。プレイヤーが開発者アプリを登録する必要はありません。ログインは選択したサービスのサイトで行ってください。Party がそのパスワードを求めることはありません。接続サービスは更新用のアクセス権限とアカウント名を暗号化して保持し、成績はブラウザーに保存します。接続を解除すると Party が保持する権限を削除します。Fish の場合は、[認可済みアプリ](https://auth.diving-fish.com/apps)からもアクセスを取り消せます。LXNS の手順は下の専用セクションにあります。Maishift と Kamaitachi は、アカウントの認可を使わず公開データを参照します。

**更新は、成績管理サービスに保存済みのデータを読み直します。SEGA、Wahlap、maimai NET から新しい成績を取得する操作ではありません。** 先に提供元を更新してください。更新日時はプレイ日時ではありません。取得に失敗しても保存済みの成績は残ります。利用可否を確認できなかった場合は再試行してください。運営者が無効にしたとは限りません。

<a id="session-report"></a>

## Session Report / Party プレイヤーファイル

1. Party で Session Report を開き、ファイルの読み込み方法を選びます。Session Report または Party から取得した圧縮プレイヤーファイル（.gz）を選択してください。
2. 公開されたレポートを使う場合は URL の方法を選びます。公開レポートはブラウザーからのアクセスを許可する必要があります。非公開レポートはそのサイトでログインし、**Open in Party** を選ぶか、プレイヤーファイルをダウンロードしてください。非公開レポートの更新にもこの受け渡しが必要です。
3. プロフィールを確認し、今回のみ読み込むか、記憶するかを選びます。

Session Report は Kamaitachi のデータと保持された履歴からファイルを作ります。Kamaitachi 自体のアカウントバックアップではありません。

<a id="maishift"></a>

## Maishift

1. [Maishift のガイド](https://maimai.shiftpsh.com/en/guide)に従い、NET へのログインとブックマークレットの操作を各サイトで行って成績を更新します。
2. Party で Maishift を開き、ユーザー名または公開プロフィール URL を入力します。パスワードやプレイヤー側の開発者設定は不要です。
3. 地域と PB を確認して読み込みます。

日本版と海外版は別々に扱います。URL の `@jp`、`@intl`、`@na` で対象を指定できます。北米は海外版の成績を使用し、対象譜面が異なります。地域のないユーザー名では海外版を要求し、Maishift が返した地域を使います。両方ある場合に日本版を選ぶには `@jp` の URL を使用してください。表示言語は地域を変更せず、記憶した接続は同じ地域を更新します。

読み込むのはプレイ済み譜面の PB で、プレイ履歴ではありません。Maishift 固有のバックアップファイルには未対応です。既存の Session Report / Party ファイルは上の方法を使ってください。

<a id="kamaitachi"></a>

## Kamaitachi

1. 成績のある既存の Kamaitachi maimai DX プロフィールを使います。最新の成績がなければ、先に[インポートページ](https://kamai.tachi.ac/import)から Kamaitachi を更新してください。Party は Kamaitachi のアカウント作成やアーケードの成績アップロードを行いません。
2. Party で Kamaitachi を開き、ユーザー名、数値のユーザー ID、または `https://kamai.tachi.ac/u/username` 形式のプロフィール URL を入力します。
3. 表示されたプレイヤーと PB をよく確認してください。公開データの参照では、アカウントの所有者を認証しません。今回のみ読み込むか、後で更新できるようプロフィールを記憶します。

Party は、パスワードや API キーを使わず Kamaitachi の公開 API を読みます。STD と DX の譜面を含む maimai DX の保存済み PB を読み込みます。別のゲームとして扱われる旧 maimai や、生涯のプレイ履歴は対象外です。数値 ID で改名後もアカウントを区別します。旧来のユーザー名に基づく Session Report の識別情報とは別に扱います。

プレイヤーが見つかっても maimai DX の成績がない場合は、先に Kamaitachi に成績を追加してから再試行してください。Party の更新は、Kamaitachi に保存済みのデータを読み直します。取得日時は最後のプレイ日時や提供元での同期日時ではありません。

交換ファイルは Kamaitachi の **BATCH-MANUAL をアップロード**から選択します。[ファイル形式の制限](#tachi)を確認してください。Kamaitachi のアカウントバックアップではありません。

<a id="diving-fish"></a>

## Diving-Fish / 水鱼查分器

この接続は、Diving-Fish に保存済みの中国地域の成績を読み込みます。現在のログイン画面、プロフィール設定と設定ガイドは中国語です。

1. [Diving-Fish](https://maimai.diving-fish.com/)を開いてログインし、成績管理サービスの利用規約に同意して、成績が表示されることを確認します。
2. Fish を初めて使う場合は登録し、案内に従ってメール認証を済ませてから[成績取り込みガイド](https://maimai.diving-fish.com/manual/docs/category/%E5%AF%BC%E5%85%A5%E6%88%90%E7%BB%A9/)に従います。アカウントを作るだけではアーケードの成績は追加されません。Fish への取り込みを済ませてから Party に戻ってください。
3. 正確な成績を得るには、Fish の **编辑个人资料**（プロフィール編集）で **对非网页查询的成绩使用掩码**（ウェブ以外の問い合わせで成績をマスクする）を無効にします。Party はこの設定を確認できません。**禁止公开接口使用我的成绩（授权不受影响）**は有効のままで構いません。公開問い合わせの制限は、認可した接続を妨げません。
4. Party で Diving-Fish を開き、**成績を更新しました。**と**成績のマスクを無効にしました。**にチェックを入れて接続します。各項目の **?** で説明を確認できます。`auth.diving-fish.com` でログインしてプロフィールと成績の読み取り権限を許可します。
5. Party に戻り、表示されたプレイヤー、PB 数と未一致の譜面を確認してから、今回のみ読み込むか接続を記憶します。

Fish に成績がなければ、先に Fish を更新してください。Party に利用規約への同意を求められた場合は、Fish を開いて同意し、成績を確認します。記憶済みの接続は、その後更新を再試行できます。初回の読み込みに失敗すると未確定の接続は破棄されるため、設定を済ませてから接続し直してください。

更新は Fish の保存済み PB を読みます。新しいアーケードの成績を Fish に取り込んだり、プレイ履歴を作ったりはしません。取得日時は Party が Fish を読んだ時点で、最後にプレイした日時ではありません。取得失敗や空の結果でも保存済みデータは残り、今回の応答に含まれない PB も保持されます。未一致の譜面は対応を推測せずに保持します。

今後のアクセスを止めるには、Party で接続を解除してください。[Fish の認可済みアプリ](https://auth.diving-fish.com/apps)で Party の権限を取り消すこともできます。権限が失効したり取り消されたりした場合は、接続し直してください。このブラウザーに保存済みの成績は、Party で別途削除できます。

<a id="lxns"></a>

## LXNS / 落雪咖啡屋

LXNS アカウントに紐づけ済みの、中国地域の maimai DX 成績を読み込む接続です。LXNS の設定ガイドは中国語です。

1. [LXNS](https://maimai.lxns.net/) にログインし、成績を確認します。表示されない場合は、先に[ゲームデータの同期ガイド](https://maimai.lxns.net/docs/sync)に従ってください。アカウント作成だけでは成績は追加されません。初回のオンライン同期でゲームデータをアカウントに紐づけます。
2. Party で LXNS を開き、**成績を更新しました。**にチェックを入れてから、**LXNS に接続**を選びます。説明は **?** で確認できます。`maimai.lxns.net` でログインし、読み取り専用のアクセスを許可してください。プレイヤーによる開発者アプリの登録や個人用 API キーは不要です。
3. Party に戻り、プレイヤー、中国地域、自己ベスト数、未一致の譜面を確認します。今回のみ読み込むか、接続を記憶して後から更新できます。

読み込むのは保存済みの自己ベストで、プレイ履歴ではありません。更新は LXNS を読み直す操作で、ゲームセンターの成績の同期は開始しません。空の結果や取得失敗でも保存済みデータは残ります。読み込める成績がない場合は、先に LXNS に同期してください。初回の読み込みに失敗すると未確定の接続は破棄されるため、その後もう一度接続します。

Party で接続を解除すると、保持しているアクセス許可を削除します。[認可の案内](https://maimai.lxns.net/docs/mcp)にあるように、LXNS のプロフィールの **第三方应用**（サードパーティーアプリ）からも Party の許可を取り消せます。ブラウザーに保存済みの成績は、Party で別途削除できます。

<a id="mai-tools"></a>

## mai-tools / DX Rating Analyzer

1. [導入ガイド](https://myjian.github.io/mai-tools/#howto)に従い、該当する公式 NET にログインして **Analyze Self DX Rating** を実行します。
2. **Share → Export as JSON (all records)** で `maimai-scores-<timestamp>.json` を保存します。
3. Party で mai-tools を開き、JSON ファイルを選択します。

ツールの DXRating 形式で出力した場合は下の DXRating を使います。B15/B35 は一部のみです。クリップボードの TSV や画像は使えません。

<a id="dxrating"></a>

## DXRating

1. 成績のあるブラウザーで [My rating](https://dxrating.net/rating) を開きます。必要なら先に DXRating の読み込み機能で成績を登録します。
2. **Export... → Export to JSON (all records)** で `dxrating.export-<timestamp>.json` を保存します。
3. Party で DXRating を開き、JSON ファイルを選択します。

**Export to JSON (B50 records only)** にも対応しますが、B50 のみです。画像は成績ファイルではなく、エクスポート操作だけで筐体から新しい成績を取得することもありません。

<a id="tomomai"></a>

## Tomomai

1. 上級者向けの API 応答読み込みです。Tomomai の **Settings → Developer** で説明されている個人キーと、信頼できる API クライアントを使います。Party に API キーの入力欄はありません。
2. 利用先の `GET /api/v1/snapshots/latest?region=<region>` の正常な JSON 応答本文だけを保存します。スナップショットのメタデータと楽曲成績の読み取り権限が必要です。[個人キーのガイド](https://github.com/shedaniel/tomomai/blob/ee29589979ed37eb0203ab00781d5e70c984ccb2/apps/main/content/developer/guides/api-keys.mdx)を参照してください。
3. Party で Tomomai を開いてアカウント名を入力し、エクスポートしたデータの地域を選んでから、JSON ファイルを選択します。

B50 は一部の成績です。最近の成績だけの応答は観測レコードとして保持し、PB やプレイ数には加算しません。1 ページを全履歴とは扱いません。通常の成績 JSON ダウンロードボタンは未確認です。画像や通信アーカイブには未対応です。

<a id="jietng"></a>

## JiETNG v2

1. 必要に応じて [JiETNG の設定と成績同期](https://jietng.matsuk1.com/en/guide/getting-started)を完了します。
2. LINE の個人チャットで `export json`、Discord 連携が使える場合は `/export` を実行します。リンクが期限切れになる前に JSON を保存してください。
3. Party で JiETNG v2 を開き、エクスポートしたデータに合わせて日本版または海外版を選んでから、`JiETNG-*` JSON ファイルを選択します。

ネイティブのバージョン 2 JSON に対応します。XML や B50 画像は使えません。ベスト成績は PB、最近の成績は観測レコードとして保持し、プレイ数を作り出しません。ボットの Import Token を Party に入力しないでください。

<a id="aqua"></a>

## AquaDX / AquaNet

1. 利用しているサーバーの AquaNet でログインし、設定の **Mai → Export Player Data** を選びます。
2. `AquaDX_maimai2_export_<name>.json` を保存します。
3. Party で AquaDX を開き、JSON ファイルを選択します。次回以降も同じアカウント名と、別項目のサーバー名を使ってください。

ネイティブの maimai DX ファイルには PB と保持されたプレイログが含まれますが、生涯の全履歴とは限りません。派生版の仕様は異なる場合があります。**Export in Batch Manual (for Tachi)** はプレイの識別情報が失われる別形式なので、可能ならネイティブ形式を使ってください。SQL や全ゲームのバックアップには未対応です。プライベートサーバーを Party に公開する必要はありません。

<a id="tachi"></a>

## Tachi BATCH-MANUAL 交換ファイル

1. AquaNet の **Export in Batch Manual (for Tachi)** など、明示的に BATCH-MANUAL を出力する機能を使います。
2. Party で Kamaitachi を開き、**BATCH-MANUAL をアップロード**から変更していない JSON を選びます。以降も同じアカウント名とサーバー名を使います。
3. 観測レコードを確認して読み込みます。

Kamaitachi のアカウントバックアップではなく交換形式です。maimai DX（`maimaidx`、Single）のみ対応します。安定したプレイ ID がなく、PB のスナップショットとも判断できないため、**日時があっても PB やプレイ数には加算しません。**

<a id="file-exports"></a>

## ファイルの識別と制限

ファイルにはローカルのアカウント名と地域、プライベートサーバーには別のサーバー名を指定します。ログイン情報ではありません。次回も同じ値を使い、パスワード、トークン、サーバー URL は入力しないでください。ファイルはブラウザー内で処理し、成績は共有リンクや利用状況分析には含めません。

提供元、地域、サーバーが異なるデータは別プレイヤーです。OAuth と手入力のファイル識別情報も別です。別プレイヤーを読み込むとプロフィールを切り替えます。一部のみのファイルで省略された PB は残します。履歴には安定したイベント識別情報のある明示的なプレイだけを追加し、タイムゾーンが不明なら不明のまま保持します。

楽曲、アーティスト、STD/DX、難易度が一意に一致した譜面を、利用可能な提供元メタデータと照合します。曖昧・未一致のレコードは推測で紐付けずに保持します。未対応の宴譜面の除外数はプレビューで示します。不明な値を補いません。

使えるスナップショット日時がない場合はファイル日時で PB を並べます。**古いエクスポートを新しいファイルとして保存すると、新しい PB を置き換えることがあります。** 確認してから読み込んでください。スナップショットやファイルの日時からプレイ日時やセッションを作ることはありません。
