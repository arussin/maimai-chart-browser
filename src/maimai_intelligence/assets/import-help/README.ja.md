# プレイヤーデータの読み込み

**プレイヤーデータの読み込み**で利用しているサービスを開き、その中の**読み込み方法**を選びます。以下の手順に従い、プレイヤー、地域、自己ベスト（PB）、未一致の譜面と除外されたレコードをプレビューで確認してください。記憶するとこの端末に保存され、今回のみの読み込みはこのタブで有効です。

<a id="direct-connections"></a>

## 接続と更新

Diving-Fish への接続が利用可能な場合、アカウントへのアクセスを許可して成績を読み込めます。プレイヤーが開発者アプリを登録する必要はありません。ログインは Diving-Fish のサイトで行ってください。Party がそのパスワードを求めることはありません。接続サービスは更新用のアクセス権限とアカウント名を暗号化して保持し、成績はブラウザーに保存します。接続を解除すると Party が保持する権限を削除します。[Fish の認可済みアプリ](https://auth.diving-fish.com/apps)からもアクセスを取り消せます。Maishift と Kamaitachi は、アカウントの認可を使わず公開データを参照します。

**更新は、成績管理サービスに保存済みのデータを読み直します。SEGA、Wahlap、maimai NET から新しい成績を取得する操作ではありません。** 先に提供元を更新してください。更新日時はプレイ日時ではありません。取得に失敗しても保存済みの成績は残ります。利用可否を確認できなかった場合は再試行してください。運営者が無効にしたとは限りません。

<a id="session-report"></a>

## Session Report / Party プレイヤーファイル

1. Party で Session Report を開き、ファイルの読み込み方法を選びます。Session Report または Party から取得した圧縮プレイヤーファイル（.gz）を選択してください。
2. 公開されたレポートを使う場合は URL の方法を選びます。公開レポートはブラウザーからのアクセスを許可する必要があります。非公開レポートはそのサイトでログインし、**Open in Party** を選ぶか、プレイヤーファイルをダウンロードしてください。非公開レポートの更新にもこの受け渡しが必要です。
3. プロフィールを確認し、今回のみ読み込むか、記憶するかを選びます。

Session Report は Kamaitachi のデータと保持された履歴からファイルを作ります。Kamaitachi 自体のアカウントバックアップではありません。

<a id="maishift"></a>

## Maishift

1. [Maishift のガイド](https://maimai.shiftpsh.com/en/guide)に従い、NET へのログインとブックマークレットの操作を各サイトで行って成績を更新します。
2. Party で Maishift を開き、**公開プロフィール**を選んでユーザー名または公開プロフィール URL を入力します。パスワードやプレイヤー側の開発者設定は不要です。
3. 地域と PB を確認して読み込みます。

日本版と海外版は別々に扱います。URL の `@jp`、`@intl`、`@na` で対象を指定できます。北米は海外版の成績を使用し、対象譜面が異なります。地域のないユーザー名では海外版を要求し、Maishift が返した地域を使います。両方ある場合に日本版を選ぶには `@jp` の URL を使用してください。表示言語は地域を変更せず、記憶した接続は同じ地域を更新します。

読み込むのはプレイ済み譜面の PB で、プレイ履歴ではありません。Maishift 固有のバックアップファイルには未対応です。既存の Session Report / Party ファイルは上の方法を使ってください。

<a id="kamaitachi"></a>

## Kamaitachi

1. 成績のある既存の Kamaitachi maimai DX プロフィールを使います。最新の成績がなければ、先に[インポートページ](https://kamai.tachi.ac/import)から Kamaitachi を更新してください。Party は Kamaitachi のアカウント作成やアーケードの成績アップロードを行いません。
2. Party で Kamaitachi を開き、**ユーザー名で読み込む**を選びます。ユーザー名、数値のユーザー ID、または `https://kamai.tachi.ac/u/username` 形式のプロフィール URL を入力します。
3. 表示されたプレイヤーと PB をよく確認してください。公開データの参照では、アカウントの所有者を認証しません。今回のみ読み込むか、後で更新できるようプロフィールを記憶します。

Party は、パスワードや API キーを使わず Kamaitachi の公開 API を読みます。STD と DX の譜面を含む maimai DX の保存済み PB を読み込みます。別のゲームとして扱われる旧 maimai や、生涯のプレイ履歴は対象外です。数値 ID で改名後もアカウントを区別します。旧来のユーザー名に基づく Session Report の識別情報とは別に扱います。

プレイヤーが見つかっても maimai DX の成績がない場合は、先に Kamaitachi に成績を追加してから再試行してください。Party の更新は、Kamaitachi に保存済みのデータを読み直します。取得日時は最後のプレイ日時や提供元での同期日時ではありません。

<a id="diving-fish"></a>

## Diving-Fish / 水鱼查分器

この接続は、Diving-Fish に保存済みの中国地域の成績を読み込みます。現在のログイン画面、プロフィール設定と設定ガイドは中国語です。

1. [Diving-Fish](https://maimai.diving-fish.com/)を開いてログインし、成績管理サービスの利用規約に同意して、成績が表示されることを確認します。
2. Fish を初めて使う場合は登録し、案内に従ってメール認証を済ませてから[成績取り込みガイド](https://maimai.diving-fish.com/manual/docs/category/%E5%AF%BC%E5%85%A5%E6%88%90%E7%BB%A9/)に従います。アカウントを作るだけではアーケードの成績は追加されません。Fish への取り込みを済ませてから Party に戻ってください。
3. 正確な成績を得るには、Fish の **编辑个人资料**（プロフィール編集）で **对非网页查询的成绩使用掩码**（ウェブ以外の問い合わせで成績をマスクする）を無効にします。Party はこの設定を確認できません。**禁止公开接口使用我的成绩（授权不受影响）**は有効のままで構いません。公開問い合わせの制限は、認可した接続を妨げません。
4. Party で Diving-Fish を開き、**直接接続**を選びます。マスクを無効にしたことを確認して接続し、`auth.diving-fish.com` でログインしてプロフィールと成績の読み取り権限を許可します。
5. Party に戻り、表示されたプレイヤー、PB 数と未一致の譜面を確認してから、今回のみ読み込むか接続を記憶します。

Fish に成績がなければ、先に Fish を更新してください。Party に利用規約への同意を求められた場合は、Fish を開いて同意し、成績を確認します。記憶済みの接続は、その後更新を再試行できます。初回の読み込みに失敗すると未確定の接続は破棄されるため、設定を済ませてから接続し直してください。

更新は Fish の保存済み PB を読みます。新しいアーケードの成績を Fish に取り込んだり、プレイ履歴を作ったりはしません。取得日時は Party が Fish を読んだ時点で、最後にプレイした日時ではありません。取得失敗や空の結果でも保存済みデータは残り、今回の応答に含まれない PB も保持されます。未一致の譜面は対応を推測せずに保持します。

今後のアクセスを止めるには、Party で接続を解除してください。[Fish の認可済みアプリ](https://auth.diving-fish.com/apps)で Party の権限を取り消すこともできます。権限が失効したり取り消されたりした場合は、接続し直してください。このブラウザーに保存済みの成績は、Party の記憶解除またはクリア操作で別途管理します。
