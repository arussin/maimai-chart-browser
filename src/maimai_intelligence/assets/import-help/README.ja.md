# プレイヤーデータの読み込み

自己ベストを譜面ブラウザーに読み込めます。読み込む前にプロフィールを確認してください。成績はブラウザー内に保存され、共有リンクやアクセス解析には含まれません。

<a id="session-report"></a>

## Session Report：ファイルまたはホストされたレポート

Session Reportは、Kamaitachiのデータと保存済みの履歴からプレイヤーファイルを作成します。次の2つの方法は同じプレイヤーデータ形式を使用します。

ファイルをアップロード：Session Reportから圧縮プレイヤーファイル（.gz）をダウンロードし、「ファイルをアップロード」で選択してください。この端末に保存するかどうかは選べます。保存しない場合は、現在のタブでのみ保持されます。

ホストされたSession Report：レポートのURLを貼り付けてください。明示的に公開され、ブラウザーからのクロスオリジンアクセスを許可したレポートは直接読み込めます。「保存して更新」で、この端末に接続情報を保存します。非公開レポートはレポート側でログインし、「Partyで開く」を選ぶか、プレイヤーファイルをダウンロードしてください。非公開レポートの更新にもこの操作が必要です。

別のプレイヤーを読み込むと表示中のプロフィールが切り替わります。異なるプレイヤーの記録は統合されません。読み込みに失敗しても既存の成績は保持されます。

<a id="maishift"></a>

## Maishift

「プレイヤーデータを読み込む」で Maishift を選択してください。自分の公開ユーザー名またはプロフィールURLを入力してください。読み込み時、または保存して更新することに同意した場合のみ、Partyの読み込みサービスが公開プロフィールとプレイ済み譜面の自己ベストを取得します。Maishiftのパスワードは不要です。

同じユーザー名にインターナショナル版と日本版の両方の記録がある場合があります。両者は別々に保持されます。北米はインターナショナル版の記録を使用しますが、選曲できる譜面が異なります。@jp、@intl、@naを含むURLでは対応する記録を選択します。ユーザー名だけ、または地域を含まないURLの場合は、まずインターナショナル版を要求し、Maishiftが実際に返した地域を使用します。両方ある場合はインターナショナル版が選ばれます。日本版を読み込むには、@jpを含むプロフィールリンクを貼り付けてください。保存後の更新はその地域に固定され、表示言語から地域を決めることはありません。

プレビューにはプレイヤー、読み込む自己ベストの件数、一致しない記録や除外された記録が表示されます。ユーザー名から選択した Maishift プロフィールを開けます。レーティングバッジには Maishift が報告した合計値を表示します。譜面別レーティングには同サービスの整数の寄与値を使用し、絞り込みや並べ替えにも反映します。欠損値や推定値は不明のまま扱います。

低難度やSTD/DXを含め、返されたすべてのプレイ済み譜面の自己ベストを確認します。確認済みの正確な対応がある記録はブラウザーに表示します。未対応の記録も保持し、譜面の識別情報が不足する記録は別に集計します。自己ベストのスナップショットからプレイ日時やセッションを作ることはありません。

「読み込んで保存」で、このブラウザーにプロフィールと接続情報を保存します。「今回だけ読み込む」では現在のタブでのみ保持します。保存済みの成績を先に復元し、ページが表示中かつオンラインであるなどの条件を満たしたときに更新を確認します。同じ読み込み元への自動確認は、複数のタブを通じて15分に最大1回です。「今すぐ更新」には30秒の待ち時間があり、読み込み元の制限によりさらに待つ場合があります。

「保存したプレイヤーデータを削除」で、保存済みプロフィールと接続情報を削除し、すべてのタブで更新を停止します。すでに表示中の成績は、再読み込みまで残る場合があります。終了したテスト用ブラウザーのデータは別に保持されます。通常サイトで再度読み込んでください。ユーザー名は公開データの読み込み元を識別するためのもので、アカウントの所有権を証明したり、ユーザー名の再割り当てを検出したりするものではありません。
