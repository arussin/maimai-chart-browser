# 导入玩家数据

将个人最佳成绩导入谱面浏览器。导入前请确认玩家资料。成绩保存在你的浏览器中，不会加入分享链接或分析数据。

<a id="session-report"></a>

## Session Report：文件或托管报告

Session Report 使用你的 Kamaitachi 数据和保留的历史记录生成玩家文件。以下两种方式使用相同的玩家数据格式。

上传文件：从 Session Report 下载压缩玩家文件（.gz），选择“上传文件”，然后选取该文件。可选择“在此设备上记住”。不勾选时，导入数据仅在当前标签页中保留。

托管的 Session Report：粘贴报告网址。明确公开且允许浏览器跨域访问的报告可以直接读取。“记住并刷新”会在此设备上保存连接。对于私人报告，请在报告网站登录并选择“在 Party 中打开”，或下载玩家文件。私人报告需要通过这种辅助方式刷新。

导入其他玩家时会切换当前资料，不会合并不同玩家的数据。读取失败时，现有成绩会保留。

<a id="maishift"></a>

## Maishift

在“导入玩家数据”中选择 Maishift。输入你自己的公开用户名或资料网址。只有在导入或同意记住并刷新后，Party 的导入服务才会读取公开资料和已游玩谱面的最佳成绩。无需提供 Maishift 密码。

同一用户名可以同时拥有国际版和日本版记录，两者保持独立。北美使用国际版记录，但可选谱面不同。包含 @jp、@intl 或 @na 的网址会选择对应记录。仅输入用户名或不含区域的网址时，Party 会先请求国际版，并使用 Maishift 实际返回的区域。若两者都有，默认选择国际版；如需导入日本版，请粘贴含 @jp 的资料网址。记住后的刷新固定使用该区域；界面语言不会决定记录区域。

预览会显示玩家、导入的最佳成绩数量，以及未匹配或被排除的记录。用户名链接到所选的 Maishift 资料。Rating 徽章使用 Maishift 提供的玩家总 Rating。单谱面 Rating 使用该来源的整数贡献值，可用于筛选和排序。缺失或估算的 Rating 保持未知。

导入会考虑返回的所有已游玩谱面最佳成绩，包括低难度和 STD/DX 谱面。通过已审核精确匹配的成绩会显示在浏览器中。未匹配记录会保留；缺少足够谱面标识的记录会单独计数。最佳成绩快照不会生成游玩日期或游玩场次。

“导入并记住”会在此浏览器保存资料和连接。“仅导入一次”只在当前标签页保留。记住后会先恢复已保存的成绩，再在页面可见且联网等条件满足时检查更新，同一来源在多个标签页之间最多每 15 分钟自动尝试一次。“立即刷新”的冷却时间为 30 秒；来源限制可能要求等待更久。

“忘记已保存的玩家数据”会删除保存的资料和连接，并停止所有标签页的刷新。已显示的成绩可能保留至重新加载。旧测试浏览器的数据保持独立；请在主站重新导入。用户名只用于识别公开来源，不能证明账号所有权，也不能防止用户名被重新分配。
