# Import player data

Bring your personal bests into the chart browser. Review the profile before importing. Scores stay in your browser and are not added to shared links or analytics.

<a id="session-report"></a>

## Session Report: file or hosted report

Session Report prepares a player file from your Kamaitachi data and retained history. Both options below import the same player-data format.

Upload a file: download the compressed player file (.gz) from Session Report, choose Upload a file, then select it. Remember on this device is optional. Without it, the import lasts for this tab.

Hosted Session Report: paste your report URL. An explicitly public report that allows browser access can be read directly. Remember and refresh keeps its connection on this device. For a private report, open the report, sign in there and choose Open in Party, or download its player file. Private reports need this assisted refresh.

Importing another player switches the active profile; different players are never combined. Your existing scores remain if a read fails.

<a id="maishift"></a>

## Maishift

Choose Maishift in Import player data. Enter your own public username or profile URL. Party's import service reads the public profile and played-chart PBs only when you import or consent to remembered refresh. No Maishift password is needed.

One username can have both International and Japan records. These remain separate; North America uses International records with different chart availability. A URL containing @jp, @intl or @na selects that record set. For a username or URL without a region, Party requests International and uses the region Maishift returns. If both exist, International is selected; paste the @jp profile link to import Japan instead. Remembered refresh stays in that region; display language does not select it.

The preview shows the player, imported PB count and any unmatched or excluded records. The username links to the selected Maishift profile. The rating badge uses the total profile rating reported by Maishift. Chart ratings use its integer contribution values and work with rating filters and sorting. Missing or estimated ratings remain unknown.

All returned played-chart PBs are considered, including lower difficulties and STD/DX variants. Exact reviewed chart matches appear in the browser. Unmatched records are preserved; records without enough chart identity are counted separately. PB observations do not create play dates or sessions.

Import & remember saves the profile and connection in this browser. Import once keeps it only in this tab. Remembered refresh restores saved scores first, then checks on an eligible visible/online visit at most once per source per 15 minutes across tabs. Refresh now has a 30-second cooldown; upstream limits may require longer.

Forget remembered player data removes the saved profile and connection and stops refresh across tabs. Scores already visible may remain until reload. Data from the retired test browser stays separate; import again on the main site. A username identifies the public source; it does not prove ownership or protect against reassignment.
